# Inventaire vocal

Petite application pour dicter un inventaire de fleurs à voix haute (« 3 roses à 4 euros »).
Les saisies sont enregistrées dans un Google Sheets via un script Google protégé par un code d'accès,
et se synchronisent entre l'ordinateur et le téléphone.

- Dictée vocale (Chrome, Safari Mac et iPhone)
- Une page par fournisseur, totaux par ligne, par fournisseur et récapitulatif
- Export Excel et impression
